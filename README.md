# Japan Working Holiday Visa — Fillable Resume (履歴書) Template

A clean, modern, interactive **fillable PDF resume template** specifically formatted for the **Japan Working Holiday Visa application**.

Official embassy PDFs are often static, non-fillable scanned documents or rigid forms. This project provides a precise, professionally styled, interactive PDF template generated using Python (`ReportLab`) that allows applicants to type directly into form fields using any modern PDF viewer or web browser.

## How to Use

### Option 1: Use the Ready-to-Fill PDF (Simplest)
1. Download [Working_Holiday_Visa_Resume_Fillable.pdf](./Working_Holiday_Visa_Resume_Fillable.pdf) from this repository.
2. Open the file in **Adobe Acrobat**, **Preview** (macOS), **Edge**, **Chrome**, or any PDF editor.
3. Fill in your information directly into the input boxes.
4. Save and print/export the completed PDF for your visa application.

---

### Option 2: Build or Customize with Python
If you want to modify font sizes, spacing, or add custom fields, you can regenerate the PDF using the Python script [main.py](./main.py).
It is currently managed with [uv](https://docs.astral.sh/uv/) and can be run with `uv run main.py`.
